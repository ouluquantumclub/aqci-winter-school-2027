# Applied Quantum Computing International Winter School 2027

Static GitHub Pages website for the **Applied Quantum Computing International Winter School**, Oulu, Finland, March 2027.

## Recommended repository

Create a new public repository under the `ouluquantumclub` GitHub organization:

`winter-school-2027`

The site can then be published at:

`https://ouluquantumclub.github.io/winter-school-2027/`

## Upload

Upload all files and the `assets` folder to the repository root.

Then open:

**Settings → Pages → Build and deployment → Deploy from a branch**

Choose:

- Branch: `main`
- Folder: `/ (root)`

## Main files

- `index.html`
- `styles.css`
- `script.js`
- `assets/aq-winter-school-logo.png`
- `assets/oulu-winter.webp` or `.png`
